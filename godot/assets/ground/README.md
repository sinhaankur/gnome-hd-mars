# Mars ground materials — tileable PBR texture sets

Generated by `tools/build_ground_materials.py` (procedural, our own, no
third-party license). Pure-numpy tileable value-noise — **genuinely seamless**
(opposite edges match to <0.5%) with real normal + roughness variation, not the
flat normals / constant roughness the earlier Cycles-bake version produced. Each
surface is a tiling 1024² set:

| Surface | What it is | Use |
|---|---|---|
| `soil/`  | Dry oxidised rust-red regolith | default Mars ground |
| `sand/`  | Fine wind-blown tan sand, dune ripples | dunes / basins |
| `ice/`   | Pale blue-white cracked water ice | polar / subsurface exposure |
| `water/` | Dark glossy liquid (coolant/pool) | installations, gameplay pools |

Each folder has `albedo.png`, `normal.png`, `roughness.png`.

## Using in Godot

The terrain is a **shader**, so tile these PNGs across the ground material rather
than placing meshes. On a `StandardMaterial3D` (or the terrain shader):

```gdscript
var mat := StandardMaterial3D.new()
mat.albedo_texture       = load("res://assets/ground/soil/albedo.png")
mat.normal_enabled       = true
mat.normal_texture       = load("res://assets/ground/soil/normal.png")
mat.roughness_texture    = load("res://assets/ground/soil/roughness.png")
mat.uv1_scale            = Vector3(40, 40, 1)   # tile density across terrain
```

Set both textures' import **Repeat = Enabled** in Godot so they tile without seams.

## Status in the terrain

The terrain shader (`scripts/mars_terrain.gd`) uses `soil/albedo.png` as its
`ground_albedo` triplanar blend (replacing the old mossy photogrammetry scan).
The scanned `mars_ground_normal.png` is still used for micro-relief. The other
three sets (sand/ice/water) are staged in the library for upcoming surface
variation (dunes in basins, ice in shadowed lows, installation pools).

## Rebuild / tweak

Pure numpy — no Blender GUI needed. Any python3 with numpy works; Blender's
bundled Python is the convenient one:

```
/Applications/Blender.app/Contents/Resources/5.1/python/bin/python3.13 \
    tools/build_ground_materials.py
```

Judge these **tiled in-engine against NASA photos** (the `godot-art-pass` loop),
not as flat swatches — ground reads completely differently once tiled on terrain.
